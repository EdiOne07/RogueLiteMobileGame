# RogueLiteMobileGame
This is my Bachelor project. The project itself is a PC game that follows the Rogue Lite genre while also adding ideas of my own.

## How to Run the Program
### 1. Run the build executable
1. Navigate to Exported_Build folder.
2. Access SwordOfTimeBuild folder.
3. Double click the Sword_of_Time.exe file to start the game.

### 2. Run from the Unity Engine
1. Downlaod and install [Unity Engine](https://unity.com/download).
2. Open the Unity Hub.
3. In the Unity Hub click the Add button and select add project from disk.
4. The project should appear in the Unity Hub, thus the next step being to simply click on it and wait for the Unity Engine to start
5. In the top of the screen, right above the scene there is a start button, click on that and the game will start

Enjoy!
